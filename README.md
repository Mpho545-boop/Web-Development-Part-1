This CSS stylesheet provides the complete visual design and responsive layout for the Paws & Hearts Animal Rescue website. It begins with a CSS reset to ensure consistent styling across browsers, then defines reusable variables for colours, spacing, shadows, and border radii. The stylesheet establishes the site's typography, links, header, navigation, main content areas, and footer, creating a consistent and professional appearance throughout the website.

The code also includes specialised styling for key sections such as the home page, about section, adoption and events cards, educational content, contact details, and forms. Interactive features such as hover effects, focus states, smooth scrolling, animations, and styled buttons improve usability and accessibility. Responsive media queries adjust the layout for desktop, tablet, and mobile devices by switching between three-column, two-column, and single-column layouts. Additional accessibility features support users who prefer reduced motion, while print styles optimise the website for printing by removing unnecessary elements and simplifying colours.
